# 常见的位运算
1. 相反数，取反加一（~a+1）
2. 如果位数固定，则最小的负数转相反数过不去（取反加一和原来一样，，还是自己）
3. 或 | 只有两个0才有0          与 & 两个1才是1          异或 ^ ，不一样才是1，同时有0和1
4. ||遇到true就停止，false有穿透性  &&遇到false就停止，true有穿透性，，但是位运算每一个都运算，不会停
5. 负数如此设计->与加法一套逻辑
6. 警惕溢出
7. <<左移== * 2；；>>右移== /2（只有非负数有这个特征，负数不行）
# 打印二进制函数
>按位&上0000...1<<k位（0，1...15位）是否等于0（因为非零时这个数字的情况太多了，但事实上只要不是0，那个位上就是1）

long类型（64位）不能直接1<<48,而是1L<<48
