## 递归引入
**递归出最大值**
递归内部是把数组二分，左侧最大，右侧最大，再返回两边最大值
每次把函数内部想出现小盒子，小盒子内如果有两个盒子，那就解决一个之后再解决另一个

base case

```cpp
int maxvalue(int arr[]){
	return f(arr,0,arr.size()-1);
}

int f(int arr[],int l,int r){
	%% 首先是basecase，不能再分的情况 %%
	if(l==r){
		return arr[l];
	}
	m = (l+r)/2;
	max1 = f(arr,l,m);
	max2 = f(arr,m+1,r);
	return max1>max2 ? max1 : max2;
}
```

系统栈，没完成的先存进去（函数位，中间变量），然后往上走，直到有能运行的，出结果，返回去，弹出。

比赛能通过就不改
