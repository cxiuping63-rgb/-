## 非递归
### 用栈实现二叉树的先序遍历
```cpp
void preOrder(treenode head){
	if(head!=NULL){
		stack<int> st;
		st.push(head);
		while(st!=NULL){
			head = st.top();
			cout<<head->val<<\n;
			st.pop();
			if(head->right!=NULL){
				st.push(head->right);
			}
			if(head->left!=NULL){
				st.push(head->left);
			}
		}
	}
}
```
第一个压进去打印之后先压右再压左，之后弹出来一个，压右压左。弹出来的时候打印，之后左右全压
### 用栈实现二叉树的中序遍历
>中序遍历其实就相当于从左下开始说，之后逐渐往上，再到右下（中间每一步都是以左边为先）
```cpp
void preOrder(treenode head){
	if(head!=NULL){
		stack<int> st;
		st.push(head);
		while(st!=NULL||!stack.isempty()){
			if(st!=NULL){
				st.push(head->left);
				head = head->left;
			}
			else{
				head = st.pop();
				cout<<head->val<<\n;
				st.push(head->right);
			}
		}
	}
}
```
左边一直进直到为空弹出来打印并且转向右（后进先弹在上面树下面）

>每一个进去的都是他自己，只不过用左边作为指向的传递而已

## 后序遍历（双栈版；结合先序）
先序是中左右，中右左也一样，之后换过来左右中
把打印的东西收集到栈里面，最后一起输出
```cpp
void preOrder(treenode head){
	if(head!=NULL){
		stack<int> st;
		stack<int> stnew;
		st.push(head);
		while(st!=NULL){
			head = st.top();
			stnew.push(head);
			st.pop();
			if(head->left!=NULL){
				st.push(head->left);
			}
			if(head->right!=NULL){
				st.push(head->right);
			}
		}
		while(stnew!=NULL){
			head = stnew.top();
			cout<<head->val<<\n;
			stnew.pop();
		}
	}
}
```

因为弹出节点和打印是同步的，所以是要先把左半支都搞了然后再进中间中间完了再进右，然后每一个都是这样
