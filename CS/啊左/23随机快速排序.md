## 经典随机快排
>返回的是下标

>只有一个小于区，，最后要把随机出来的数字放在中间那个位置，然后就固定了

>小于的时候a、i，i++，a++互换，大于的时候就i++,边界不变
>**目的就是把大于x的数字包到左边
>指到的位置就是随机数的位置(与下面荷兰快排区分)**

```cpp
void quicksort1(int l,int r){
	if(l>=r){
		return;
	}
	x = arr[l+(int)(random()*(r-l+1))];
	int mid = partition1(l,r,x);
	quicksort1(l,mid-1);
	quicksort1(mid+1,r);
}
int partition1(int l,int r,int x){
	int a = l,xi = 0;
	for(int i = l;i<=r;i++){
		if(arr[i]<=x){
			swap(i,a);
			if(arr[i]==x){
				xi = a;
			}
			a++;
		}
	}
	%% 所有交换结束之后把当前位置的数字换到中间位置 %%
	swap(a,xi);
	%% 把前面一个返回回去，因为a位置已经不用动了 %%
	return a-1;
}
```
## 荷兰国旗问题划分->经典快排的优化
>有**多个一样**的的时候直接一次性排完，不用下次再搞了
>一个大于区一个小于区

>小于的时候i++，a++，a、i互换，，等于的时候就i++,边界不变，，大于的时候bi互换,b--,i不变，因为b换过来的还没有看过，不能跳过

>最后要返回两个值（位置）：等于x的最左和最右

>两个如果是平级的，但是由于要用同一个量，那么就要用另一个量把这个值记一下，，否则用完一个可能会把原来那个量改掉

```cpp
void quicksort2(int l,int r){
	if(l>=r){
		return;
	}
	int x = arr[l+(int)(random()*(r-l+1))];
	partition2(l,r,x);%% 因为这里面有两个变量，所以不建议返回值为数字，直接静态变量挺好的 %%
	int left = first;
	int right = last;
	quicksort2(l,first-1);
	quicksort2(right-1,r);
}

public static first,last;

partition2(int l,int r,int x){
	%% 这里直接赋值，因为是全局静态变量 %%
	first = l;
	last = r;
	int i = l;
	%% 这里不能直接把i++写进去，因为在后面的话调换位置之后不能加 %%
	while(i <= last){
		if(arr[i]<x){
			swap(i++,first++);
		}
		else if(arr[i]==x){
			i++;
		}
		else{
			swap(i,last--);
		}
	}
}
```
## 复杂度
>**随机行为**要**按照期望来估计**，而不是最差情况（因为没有意义）

>最差情况，，每次都是打的最右边->时间复杂度O(n^2)空间复杂度O(n)->==分叉没分上根本，直接一条线下去了==，，这个想的时候其实是为了搞最坏直接固定打最右了
>最好请况，，时间复杂度O(nlogn)空间复杂度O(logn)->*空间是深度*->**二叉树分叉了递归之后扫的次数就少**

>证明略，，**求期望得**
>**时间复杂度O(nlogn)空间复杂度O(logn)**
