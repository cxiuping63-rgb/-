>改写快排（荷兰国旗问题）->命中就直接出，没命中就只求一边，另一边舍

```cpp
public static int findkthLargest(int nums[], int k){
	return randomizedSelect(nums, nums.length - k);
}
%% 在这个数组里面i位置的数字是什么 %%
int randomizedSelect(int arr[],int i){
	int ans = 0;
	for(int l = 0,r = arr.length-1;l<=r;){
		partition2(arr,l,r,(int)(random()*(r-l+1)));
		%% 上面这个就是简单的快排的一部分，利用这个结构进行简化下面的问题 %%
		%% 下面这个i是所要求的位置,,是固定好的，不是快排里面的指向，left&&right才是partition求出来的 %%
		if(i<left)    r = left-1;
		else if(i>right)    l = right+1;
		else{
			ans = arr[i];
			break;
		}
	}
	return ans;
}
```
**时间复杂度O(n)空间复杂度O(1)**

==**快排是每层花 O(n) 处理全部，共 log n 层 → O(n log n)；==
==随机选择是每层花递减的代价处理一边，代价加起来收敛到 2n → O(n)。**==
