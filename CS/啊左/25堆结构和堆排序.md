**堆结构**：
1. 完全二叉树的编号和数组的下标相对应
2. 父节点->(i-1)/2；；左孩子->i* 2+1；；右孩子->i* 2+2
3. size管二叉树的大小
>把堆想象成在数组上的一个完全二叉树结构--但是二叉树结构是不存在的，只在我们的脑海中，，即使后面调整也是明面上只是调整数组，但是思考的时候是要想二叉树

**大根堆和小根堆**
大根堆：**子树**最**大**值在**顶**部——新来的值往上调整heapinsert
- 从下往上调（比如新来一个数）
新加入数字放入最末，之后按照二叉树的结构往上换
```cpp
void heapinsert(int arr[],int i){
	while(arr[i]>arr[(i-1)/2]){    %% 0位置也成立，因为自己不会大于自己 %%
		swap(arr,i,(i-1)/2);
		i = (i-1)/2;    %% 继续往上 %%
	}
}
```
- 从上往下调（比如0位置变小了）
先判断是否越界（size）
往最大的孩子的位置去扎（否则如果和小的换的话，新上来的这个就比下面的小了，就白换了）
或者想要比最大的还要大
```cpp
%% 第i个位置突然变化 %%
void heapify(int arr[],int i,int size){
	%% best是三者之间最强下标，，一共判断两次，俩孩子最强，目前最强与自己 %%
	int l = i*2+1;
	%% 一直往下直到把最大的换上来。进不去循环的话（没有孩子）直接结束了 %%
	while(l<size){   %% 不能取等，因为有0，size为最大+1 %%
		int best = l+1<size && arr[l+1]>arr[l] ? l+1 : l;
		best = arr[best]>arr[i] ? best : i;
		if(best==i){
			break;
		}
		swap(arr,i,best);
		i = best;    %% 当前原来的值的位置已经变成best了，因为换过位置了 %%
		l = i*2+1;
	}
```
- 时间复杂度 log n

联系堆结构和堆排序
>大根堆上一层的数一定比同一支的下一层要大

**把数组变有序**
1. 先把数组变成大根堆
	- 改size
	- 和父亲比较之后换顺序（每次换顺序直接换到不能换为止）
2. 大数归位
	- 0位置（数组最大值）和最后位置（size-1）交换位置
	- size-1（直接相当于当前的最后一个位置（也就是最大值）直接和整个堆脱节了，，因为对于我们心中的大根堆结构来说不小于size的点根本就查不到）
	- 现在0位置非常小，这样就是往下调整，把最大值搞上去
>这样做完之后**从后往前**的数字就是从**最大到最小**
```cpp
void heapsort1(int arr[]){
	int n = arr.lenth();
	%% 后面这块可以想象成这个数组本来就是存在的，然后只不过这里以二叉树的形式展现，但是都是灰色的（只是想说明这些数字直接就是固定好的，而不是一个一个写进去的，也没有二叉树这个数据结构，只不过，这个数组可以以这种形式像而已，形状有一定的优越性），然后随着i的增加，i到哪里哪里就显现出来（相当于加进去），然后就开始调新“加进来”的这个。。循环这种，到这里就说明前面都已经调好了，所以就是就调这一个直到调无可调 %%
	for(i = 0;i<n;i++){
		heapinsert(arr,i);
	}
	int size = n;
	while(size>1){
		swap(0,--size);
		heapify(arr,0,size);
	}
}
```
**复杂度**
==法一==
1. 进堆->n* log n——n* log n->log(1*...* n)<-每个数字的最差情况求和
2. 到最后->n* log n（同上，，上面从下往上，下面从上往下）
==法二==——**常量增倍法**
3. 最后一个数是log n(高度)，，n个（估算一下）
4. n个数上限是n* log n，2n个数下限是n* log n，，理论相等所以夹出这个
子矩阵数量复杂度分析同理

**从顶到底和从底到顶建堆**
把刚刚上面建堆的过程优化成O(n)
**从底到顶**
其实就是灰色的变可选是从底下开始的，从下面开始形成二叉树，上面的往下调，，而不是像上面的从下（刚变可选的）往上调。
由于上面的数字少，要调的虽然多，但是个数占比小
```cpp
void heapsort2(int arr[]){
	int n = arr.lenth();
	for(i = n-1;i>=0;i--){
		heapify(arr,i,n);     %% 这里变了，，直接就是选中数字往下调调到不能调为止 %%
	}
	int size = n;
	while(size>1){
		swap(0,--size);
		heapify(arr,0,size);
	}
}
```
