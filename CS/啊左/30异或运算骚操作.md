**异或运算的"本质"**：
- （二进制的）无进位相加
- **偶数个1消掉**
- **两个数的话 同为0，异为1**
- **和1异或，0变1，1变0**
**异或运算的性质**：
1. 满足交换律结合律
2. 与0异或之后是本身，与1异或之后是对方，与自己异或之后是0
3. 整体异或和如果是x,整体中某个部分的异或和如果是y,那么剩下部分的异或和是x^y，，一个式子三个数相互异或都能得到剩下的一个数

int getMax02(int a,int b){
	int c = a-b;
	int sa = sign(a);
	int sb = sign(b);
	int sc = sign(c);
	int diffAB = a ^ b;
	int sameAB = flip(diffAB);
	returnA = diffAB * sa + sameAB * sc;
	int returnB = flip(returnA);
	return returnA * a + returnB * b;

- 数组中有**2种数**出现了**奇数次**,其他的数都出现了偶数次,返回这2种出现了奇数次的数（性质三+上面这个算法）
根据两个数字如果不一样的话，二进制数一定至少有一位不一样，那么异或下来，至少有一位为1
然后根据这第一个不同的一位上是0还是1分成两类，就相当于做两遍上一道题
```C++
int* num(int nums[]){
	int numall;
	for(i = 0;i<nums.length();i++){
		numall ^= nums[i];
	}
	rightone = numall & (-numall);
	%%接下来所有都来一遍，用if判断来分类,这一位1一类，0一类%%
	int num1 = 0;
	for(int num : nums){
		if((num & rightone)==0){
			num1 ^= num;
		}
	}
	return new int[num1,num1 ^ numall];
}
```
- 数组中只有**1种数**出现次数少于m次,其他数都出现了m次,返回出现次数小于m次的那种数
把所有数的二进制位数上数字相加，然后算是否是m的整数倍，，如果不是的话就说明这个数某一位上是1
```C++
public static int find(int[] arr, int m) {
	// cnts[0]:0位上有多少个1
	// cnts[i]: i位上有多少个1
	// cnts[31]:31位上有多少个1
	int[] cnts = new int[32];
	for (int num : arr) {
		for (int i=0; i < 32; i++) {
			cnts[i] += (num >> i) & 1;
		}
	}
	%%上面内部是把所有位变成数组；外部是加在一起为了后面判断是否是倍数%%
	int ans = 0;
	for (int i=0; i < 32; i++) {
		%%这个余数就是这个数%%
		if (cnts[i] % m != 0) {
			ans l=1 << i;
			%%一位位归位（是1就往左移动固定的位）%%
		}
	}
	return ans;
}
```
**判断**这一位上面是否是1或者到底是几——》该数&00010000

把往特定位上变成1——》该数|00001000
把往特定位上变成0——》n & 11101111
