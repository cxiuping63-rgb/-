# 卡尔·马克思 (Karl Marx)

> *卡尔·马克思（1818—1883），德国哲学家、经济学家、社会学家，社会学三大奠基人之一*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1818年5月5日，普鲁士特里尔 |
| **逝世** | 1883年3月14日，英国伦敦，享年64岁 |
| **家庭** | 父亲是成功律师，康德和伏尔泰的信奉者；母亲来自荷兰犹太家庭。父亲改信基督教 |
| **配偶** | 燕妮·冯·威斯特法伦（1843年结婚），出身贵族家庭 |
| **教育** | 波恩大学 → 柏林大学（深受黑格尔哲学影响，加入青年黑格尔派）；耶拿大学博士（1841） |

**关键经历：**
- 1843年移居巴黎，1844年结识**恩格斯**，开始终生合作
- 1848年与恩格斯合写《共产党宣言》
- 1849年被多国驱逐后流亡伦敦，在贫困中度过余生（靠恩格斯资助）
- 在大英博物馆阅览室潜心研究数十年

## 主要著作

| 著作 | 年代 | 内容 |
|------|------|------|
| **《1844年经济学哲学手稿》** | 1844 | 提出**异化劳动**概念；揭示马克思思想中的人道主义底色 |
| **《德意志意识形态》** | 1845—1846（1932年才出版） | 与恩格斯合著；首次系统阐述**唯物史观**——社会存在决定社会意识 |
| **《共产党宣言》** | 1848 | 与恩格斯合著；宣告"一切历史都是阶级斗争的历史" |
| **《资本论》第一卷** | 1867 | 代表作；对资本主义生产方式的批判分析：剩余价值理论、商品拜物教、资本主义内在矛盾 |

## 核心概念（社会学层面）

- **历史唯物主义（唯物史观）**：社会的经济"基础"（生产力+生产关系）决定政治、法律、意识形态等"上层建筑"
- **阶级斗争**：社会发展的动力——奴隶主 vs 奴隶 → 领主 vs 农奴 → **资产阶级 vs 无产阶级**
- **异化（alienation）**：工人与劳动产品、劳动过程、人的类本质、他人的四重异化
- **商品拜物教**：人与人之间的社会关系表现为物与物之间的关系，掩盖了剥削
- **冲突论视角**：不同于涂尔干的功能论，马克思认为**冲突（而非共识）是社会变迁的引擎**

> 老师强调马克思的社会学面向：他**彻底否认不平等背后的合法性**，认为不平等是制度制造出来的，而非不可避免。他处理社会危机的方式是最激进、最无情的批判。

> 马克思与涂尔干、韦伯一样，**无法用单一学科标签框定**：他是哲学家、经济学家、社会学家、革命家。19世纪的社会学家都在解决同一个大的社会危机，只是路径不同。
