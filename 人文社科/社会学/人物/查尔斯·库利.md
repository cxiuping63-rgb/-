# 查尔斯·霍顿·库利 (Charles Horton Cooley)

> *查尔斯·霍顿·库利（1864—1929），美国社会学家，"镜中我"和"初级群体"概念提出者*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1864年8月17日，美国密歇根州安娜堡 |
| **逝世** | 1929年5月7日（癌症），享年64岁 |
| **家庭** | 父亲托马斯·库利是密歇根最高法院法官和密歇根大学法学院创始教授；库利性格害羞、内向，在父亲阴影下长大 |
| **教育** | 密歇根大学机械工程学士 → 政治学与社会学硕士 → 哲学博士（1894） |
| **任职** | 终生在密歇根大学任教：1899年开设该校第一门社会学课 → 1907年升正教授 |
| **地位** | 1905年参与创立美国社会学会；1918年任第8任主席 |

## 主要著作

| 著作 | 年代 | 概念贡献 |
|------|------|-----------|
| **《人性与社会秩序》** | 1902 | 提出**"镜中我"（looking-glass self）** |
| **《社会组织》** | 1909 | 提出**"初级群体"（primary group）**——家庭、玩伴群体、邻里 |
| **《社会过程》** | 1918 | 探讨社会组织中的非理性因素和竞争 |

## 核心概念

- **镜中我（looking-glass self）**：自我认知是三步过程——（1）我们想象自己在他人眼中的样子 →（2）想象他人对此的评价 →（3）由此产生自豪、羞耻等自我感受
- **初级群体（primary group）**：小规模的、亲密的、面对面互动的群体（如家庭）——是人性、道德和社会理想的**根本来源**
- 库利为**符号互动论**奠定了基础：认为"自我"和"社会"不是两个分离的实体，而是一体两面——心灵是社会的，社会是心理的

> 老师在第五讲（群体和社会组织）中推荐库利的文章。库利认为**家庭是最典型的初级群体**，这种群体对我们"成为社会人"至关重要。
