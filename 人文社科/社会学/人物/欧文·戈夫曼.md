# 欧文·戈夫曼 (Erving Goffman)

> *欧文·戈夫曼（1922—1982），加拿大裔美国社会学家，微观社会学和符号互动论的巨匠*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1922年6月11日，加拿大艾伯塔省曼维尔 |
| **逝世** | 1982年11月19日，美国费城（胃癌），享年60岁 |
| **家庭** | 乌克兰犹太移民后代；妹妹弗兰西斯·贝是演员 |
| **教育** | 曼尼托巴大学 → 多伦多大学学士（1945） → 芝加哥大学硕士、博士（1953） |
| **任职** | 1958—1968年伯克利加州大学；1968—1982年宾夕法尼亚大学 |
| **特点** | 极度厌恶媒体和拍照；拒绝接受采访；当选美国社会学会主席后拒绝提供照片 |

## 主要著作

| 著作 | 年代 | 内容 |
|------|------|------|
| **《日常生活中的自我呈现》** | 1956/1959 | 最著名；用**戏剧学分析**——人生如舞台；提出**印象管理**（impression management）、前台/后台 |
| **《精神病院》** | 1961 | 提出"**全控机构**"（total institution）概念；催化了精神健康改革 |
| **《污名》** | 1963 | 研究被污名化的个体如何管理"受损的身份" |
| **《互动仪式》** | 1967 | 将涂尔干的仪式理论应用于日常问候和礼貌行为 |
| **《框架分析》** | 1974 | 戈夫曼自认为的**最高成就**：回答"这里正在发生什么？" |

## 核心概念

- **拟剧论（dramaturgy）**：社会互动是表演——人人都在前台扮演角色，后台卸下面具
- **印象管理**：日常生活中控制他人对自己印象的策略
- **全控机构**：与外界隔绝、由同一权威管理的封闭场所（精神病院、监狱、军营）
- **污名**：被社会贴上的负面标签如何影响个体身份
- **面子工作（face-work）**：互动中维护自己和他人面子的日常礼仪
- **互动秩序**：面对面互动有其自身的规则和结构

> 老师推荐的《日常生活中的自我呈现》是理解**社会互动**这一讲的核心文献。戈夫曼的研究对象是日常生活中最琐碎、最不起眼的互动——但他证明这些东西值得深入研究。
