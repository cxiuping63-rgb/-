# 克洛德·列维-斯特劳斯 (Claude Levi-Strauss)

> *克洛德·列维-斯特劳斯（1908—2009），法国人类学家，结构人类学创始人，20世纪最伟大的知识分子之一*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1908年11月28日，比利时布鲁塞尔 |
| **逝世** | 2009年10月30日，法国巴黎，享年100岁 |
| **教育** | 巴黎大学（索邦）学习法律与哲学；1931年获哲学教师资格（agregation），时年22岁，为同届最年轻者 |
| **任职** | 圣保罗大学社会学客座教授（1935—1938）；纽约社会研究新学院教授（1941—1945）；法国高等研究实践学院（EPHE）研究主任（1950）；法兰西学院社会人类学讲席教授（1959—1982） |

**关键经历：**
- 生于比利时布鲁塞尔，父母为法国裔犹太人，父亲为肖像画家；一战期间与身为凡尔赛拉比的外祖父同住
- 1935—1938年任巴西圣保罗大学客座教授，期间在巴西中部和亚马逊地区对卡杜维奥人、波罗罗人、南比夸拉人和图皮-卡瓦希布人进行田野调查——这是他一生中唯一的一次系统田野工作
- 二战爆发后，因维希政权的种族法被解职；1941年经由马提尼克岛流亡美国，在纽约社会研究新学院任教，参与创办"自由高等学院"（法国流亡大学）
- 在纽约期间结识语言学家罗曼·雅各布森，受其结构语言学理论影响至深——这是结构人类学诞生的关键学术相遇
- 1942年在一次晚宴上亲历人类学大师弗朗茨·博阿斯在其怀中去世
- 1948年返回巴黎获得博士学位，论文《亲属关系的基本结构》成为结构人类学的奠基之作
- 1973年当选法兰西学术院（Academie Francaise）院士——法国最高的文学荣誉
- 2008年成为法兰西学术院首位百岁院士；2009年10月30日逝世，距其101岁生日不足一个月

## 主要著作

| 著作 | 年代 | 内容 |
|------|------|------|
| *The Elementary Structures of Kinship*（《亲属关系的基本结构》） | 1949 | 提出"联姻理论"（alliance theory），认为亲属制度的基础不是血统而是婚姻交换（尤其是"妇女交换"） |
| *Tristes Tropiques*（《忧郁的热带》） | 1955 | 文学性的自传体田野回忆录，反思人类学学科自身，使其成为法国公共知识分子 |
| *Structural Anthropology*（《结构人类学》） | 1958 | 论文集，系统阐述结构主义方法及其在亲属、神话和分类体系中的应用 |
| *The Savage Mind*（《野性的思维》） | 1962 | 论证"原始"与"文明"思维植根于同样的深层心智结构，提出"修补术"（bricolage）概念 |
| *Totemism*（《图腾制度》） | 1962 | 重新解释图腾制度，认为其本质是人类对自然物种差异的思维操作 |
| *Mythologiques*（《神话学》）四卷本：《生食与熟食》《从蜂蜜到烟灰》《餐桌礼仪的起源》《裸人》 | 1964—1971 | 宏大的神话分析工程，追踪一个南美神话在跨越整个美洲大陆过程中的结构变形 |

## 核心概念

- **结构主义（Structuralism）**：文化现象（亲属关系、神话、图腾、烹饪等）如同语言一样，是由深层的心智结构所组织的符号系统。人类学的任务不是描述表层现象，而是揭示支配这些现象的、潜藏的无意识结构。
- **二元对立（Binary Oppositions）**：人类心智普遍通过二元对立来组织世界（如生/熟、自然/文化、高/低、男/女）。一切文化和神话体系都可以被分析为这些对立项及其调和（mediation）的系统。
- **联姻理论（Alliance Theory）**：亲属制度的核心并非血统/世系（descent），而是婚姻联盟——"妇女交换"是将不同群体联结为社会的根本机制。乱伦禁忌是促使群体向外通婚（外婚制）从而建立社会联系的原始动力。
- **野性的思维（The Savage Mind / La Pensee Sauvage）**："原始人"的思维方式（具体的、分类学的、神话式的）并不劣于现代科学的思维方式（抽象的、分析的）；两者是同一心智能力的两种应用方式。野性思维通过"修补"（bricolage）——利用手头的既有材料进行创造性组合——来理解和组织世界。
- **神话的结构分析**：将神话拆解为最小的意义单元（神话素），分析其在不同版本之间的结构关系和转换规则。神话的功能是为不可调和的矛盾（如生与死、自然与文化）提供逻辑上的"调解"方案。
