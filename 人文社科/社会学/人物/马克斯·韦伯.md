# 马克斯·韦伯 (Max Weber)

> *马克斯·韦伯（1864—1920），德国社会学家、经济学家、法学家，社会学三大奠基人之一*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1864年4月21日，普鲁士埃尔福特 |
| **逝世** | 1920年6月14日，慕尼黑（肺炎，疑与西班牙流感有关），享年56岁 |
| **家庭** | 父亲是律师、公务员、国家自由党议员；母亲是虔诚的加尔文教徒 |
| **配偶** | 玛丽安妮·施尼特格（1893年结婚），德国女性主义活动家 |
| **教育** | 海德堡大学、柏林大学、哥廷根大学，法学博士（1889） |

**关键经历：**
- 1894年任弗莱堡大学经济学教授；1896年任海德堡大学讲席教授
- 1897年因与父亲激烈争吵（父亲两个月后去世），精神彻底崩溃，患严重抑郁症和失眠，**1899—1918年几乎完全停止教学**
- 1904年短暂恢复后访美，深受美国活力影响，同年开始发表《新教伦理与资本主义精神》
- 一战期间任预备役军官负责军队医院；后期成为德国扩张主义的公开批评者
- 1918—1919年参与起草魏玛宪法
- 逝世时留下未完成的巨著《经济与社会》

---

## 主要著作

| 著作 | 年代 | 内容 |
|------|------|------|
| **《新教伦理与资本主义精神》** | 1904—1905 | 最著名的作品；论证加尔文宗禁欲主义（预定论导致的焦虑→勤奋工作→世俗成功→资本积累）催生了现代资本主义的"精神" |
| **《儒教与道教》** | 1915 | 比较宗教社会学：为何中国没有自发产生资本主义 |
| **《印度的宗教》** | 1916—1917 | 分析种姓制度及其经济后果 |
| **《以学术为业》** | 1917 | 论学术生涯的本质：价值中立、专业化的必要性 |
| **《以政治为业》** | 1919 | 将国家定义为"在给定领土内成功垄断合法使用暴力的共同体" |
| **《经济与社会》** | 1922（遗著） | 未完成的巨著，涵盖官僚制、权威、法律、宗教、经济社会学 |

## 核心概念

- **理性化与祛魅**：现代性意味着世界被"祛魅"——可计算、可预测、官僚化，但失去了意义和神秘感
- **三种权威类型**：**魅力型**（靠领袖个人魅力）、**传统型**（靠世代相传）、**法理型**（靠规则和法律，即现代官僚制）
- **官僚制**：等级制、专业化、按规则办事、凭功绩晋升——理解现代组织的理想型
- **理解社会学（Verstehen）**：社会科学需要**解释性地理解**社会行动的主观意义，而非仅仅建立经验规律
- **价值中立（Wertfreiheit）**：学者应区分经验事实与价值判断，但价值不可避免地引导着研究选题

> 韦伯的思想涉及社会学、经济学、法学、历史学、宗教学等多个领域。**很难用一个学科标签框定他**。
