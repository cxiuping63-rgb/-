# 威廉·富特·怀特 (William Foote Whyte)

> *威廉·富特·怀特（1914—2000），美国社会学家，参与观察法和城市民族志的开拓者*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1914年6月27日，美国马萨诸塞州斯普林菲尔德 |
| **逝世** | 2000年7月16日，享年86岁 |
| **教育** | 斯沃斯莫尔学院（经济学学士） → 哈佛大学青年学者计划（完成田野调查） → 芝加哥大学社会学博士 |
| **任职** | 1948年起任教康奈尔大学，终生在此工作 |
| **荣誉** | 1981年任美国社会学会主席 |

**关键经历：**
- 在哈佛读博期间，在波士顿**意大利移民区"北区"（又称"柯纳维尔"）** 生活近四年
- 与当地帮派青年同吃同住18个月，以内部人身份观察街头帮派的社会结构
- 1943年出版了《街角社会》——同年患**小儿麻痹症**，此后终生拄拐行走

## 《街角社会》的核心发现

怀特区分了两种不同类型的年轻人：

| **街角青年（Corner Boys）** | **上进青年（College Boys）** |
|---|---|
| 生活以街角和本地店铺为中心 | 追求教育和向上流动 |
| 重视群体忠诚和邻里关系 | 强调个人成就 |

> 《街角社会》是**参与观察法（participant observation）**的典范之作。怀特详细记录了帮派内部的等级、成员关系、领导模式，以及帮派与帮派之间、与政客之间的关系。

> 老师在课程中提到：
> "这样的东西（街头小混混的日常互动）听起来这么琐碎……可能你在座的各位以前也是某一个小团伙的成员。但这样的东西不仅能写，而且**60多年后仍然是社会学、人类学的经典**。"
