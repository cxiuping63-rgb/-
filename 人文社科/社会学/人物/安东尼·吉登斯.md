# 安东尼·吉登斯 (Anthony Giddens)

> *安东尼·吉登斯（1938—），英国社会学家，"结构化理论"和"第三条道路"的提出者*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1938年1月18日，英国伦敦 |
| **家庭** | 中下阶层出身，父亲是伦敦交通局职员 —— 家中第一个上大学的人 |
| **教育** | 赫尔大学学士 → 伦敦政经硕士 → 剑桥大学国王学院博士 |
| **任职** | 剑桥大学教授（1987） → 伦敦政治经济学院院长（1997—2003） |
| **荣誉** | 2004年获封终身贵族（吉登斯男爵）；阿斯图里亚斯亲王奖（2002） |

## 主要著作

| 著作 | 年代 | 内容 |
|------|------|------|
| **《社会的构成》** | 1984 | **结构化理论**的集大成作 |
| **《现代性的后果》** | 1990 | 分析现代性的特征和后果 |

| **《第三条道路》** | 1998 | 深刻影响布莱尔和英国新工党的政治哲学 |

| **《气候变化的政治》** | 2009 | 晚期关注环境议题 |

## 核心概念

- **结构化理论（structuration theory）**：超越"结构决定人"vs"人创造结构"的对立——结构既是人类行动的中介，也是行动的结果（"结构的二重性"）
- **现代性理论**：反思性现代化、脱域、专家系统、本体性安全
- **第三条道路**：超越传统左右之分
- 老师特别提到的特点：**吉登斯特别强调社会学的历史性**——社会学要帮我们搞清楚"人的社会何以成为今天这个样子，我们怎么一步步走到今天的"

> 老师非常欣赏吉登斯的**历史性视角**：很多东西看起来是"一出生就给定"的——但经过漫长历史过程才演变而来。社会学就是要去揭示这个历史过程。
