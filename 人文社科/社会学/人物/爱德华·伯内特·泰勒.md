# 爱德华·伯内特·泰勒 (Edward Burnett Tylor)

> *爱德华·伯内特·泰勒（1832—1917），英国人类学家，文化人类学创始人，提出了人类学史上最经典的文化定义，"文化是复杂的整体"*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1832年10月2日，英国伦敦坎伯韦尔 |
| **逝世** | 1917年1月2日，英国萨默塞特郡惠灵顿，享年84岁 |
| **教育** | 格罗夫豪斯学校（贵格会学校），16岁辍学，未获大学学位；主要通过自学成为学者 |
| **任职** | 牛津大学博物馆馆长（1883—1909）；牛津大学首任人类学高级讲师（1884—1895）；牛津大学首任人类学教授（1896—1909） |

**关键经历：**
- 出身富裕贵格会（Quaker）家庭，家族经营黄铜工厂
- 16岁因贵格会信仰（当时被禁止进入牛津和剑桥）和父母去世而辍学，进入家族工厂工作
- 23岁患上肺结核，遵医嘱于1855年前往温暖气候旅行——先后游历美国、古巴和墨西哥
- 在哈瓦那遇见民族学家亨利·克里斯蒂（Henry Christy），受邀同赴墨西哥考察托尔特克遗址，从此点燃对人类学的毕生热情
- 完全靠自学成为人类学家——系统阅读民族学、考古学、语言学和民俗学文献
- 1861年出版首部著作《安纳瓦克：古今墨西哥》
- 1865年出版《人类早期历史研究》，奠定学术声誉
- 1871年出版里程碑著作《原始文化》，提出文化的经典定义
- 1871年当选英国皇家学会会士
- 1875年获牛津大学荣誉民法博士学位
- 1883年任牛津大学博物馆馆长
- 1884年被聘为牛津大学首任人类学高级讲师
- 1888年担任首届吉福德讲座主讲人
- 1891年任英国人类学学会会长
- 1896年成为牛津大学首任人类学教授
- 1912年因学术贡献获封爵士

## 主要著作

| 著作 | 年代 | 内容 |
|------|------|------|
| 《安纳瓦克：古今墨西哥》 | 1861 | 基于墨西哥考察的民族志著作 |
| 《人类早期历史研究》 | 1865 | 探讨文明起源、语言发展、神话和习俗的比较研究 |
| 《原始文化》 | 1871 | 里程碑式著作，提出文化的经典定义和万物有灵论，系统阐述文化进化论 |
| 《人类学：人类与文明研究导论》 | 1881 | 最早的人类学教科书之一，全面介绍人类学各分支 |

## 核心概念

- **文化的经典定义**："文化或文明，就其广泛的民族学意义而言，是指一个复杂的整体，包括知识、信仰、艺术、道德、法律、习俗以及作为社会成员的人所习得的任何其他能力和习惯。"
- **万物有灵论**（Animism）：认为宗教信仰起源于原始人对梦、幻觉和死亡等现象的解释，相信灵魂和精灵的存在，这是宗教的最早形式
- **文化进化论**：人类社会经历三个普遍进化阶段——蒙昧（savagery）→ 野蛮（barbarism）→ 文明（civilization）
- **文化遗留物**（Survivals）：指从早期文化阶段遗存到后期的习俗、信仰和实践，是研究文化进化的重要证据
- **人类心理一致性**（Psychic Unity of Mankind）：主张所有人类种族属于同一物种且具有相同的心智能力，因此各地文化可以在同一进化阶梯上进行比较
