# 乔治·赫伯特·米德 (George Herbert Mead)

> *乔治·赫伯特·米德（1863—1931），美国哲学家、社会心理学家，符号互动论的奠基人*

---

## 生平

| 项目 | 详情 |
|------|------|
| **出生** | 1863年2月27日，美国马萨诸塞州南哈德利 |
| **逝世** | 1931年4月26日，芝加哥（心脏病），享年68岁 |
| **家庭** | 父亲是公理会牧师，母亲曾任霍山学院院长 |
| **教育** | 欧柏林学院 → 哈佛大学（师从威廉·詹姆斯）→ 莱比锡大学、柏林大学 |
| **任职** | 芝加哥大学哲学系教授（1894年起） |

**关键经历：**
- 在哈佛期间深受威廉·詹姆斯实用主义哲学影响
- 在德国留学期间接触冯特的实验心理学
- 1894年受约翰·杜威邀请加入芝加哥大学哲学系，与杜威密切合作
- 一生没有出版专著——他的思想通过学生课堂笔记整理出版
- 代表作《心灵、自我与社会》（Mind, Self and Society, 1934）是其逝世后由学生根据讲稿整理而成
- 芝加哥学派社会学的核心理论家之一

## 核心概念

- **符号互动论（Symbolic Interactionism）**：人们通过符号（语言、姿态）进行互动，在互动中建构意义和自我。米德是这一范式的奠基人
- **"主我"（I）与"客我"（Me）**：自我分为两个面向——"主我"是主动、自发、创造性的部分；"客我"是内化的社会期待和他人态度
- **角色扮演（Role-taking）**：人通过想象性地扮演他人的角色来理解他人的反应和期待，从而调整自己的行为
- **泛化的他人（Generalized Other）**：个体内化的整个社会群体的态度和规范，是社会控制与自我调节的机制
- **有意义的符号（Significant Symbols）**：能引发相同反应的符号（如语言），使复杂的社会互动成为可能
- **思想渊源**：深受[[马克斯·韦伯]]"有意义的行动"（meaningful social action）概念影响，将社会学研究重心从宏观制度转向微观互动

> 米德的理论强调了社会互动的**建构性**——规则和制度不是固定不变的，而是在人的日常互动中不断被界定、维持和改变。

> **相关笔记**：[[社会学概论#6.4 三大社会学范式]]（第一讲：符号互动论的实际奠基人——强调微观互动的意义建构，受韦伯"有意义的行动"概念影响；规则在人的具体互动中被界定和改变，而非确定无疑写在纸面上）
